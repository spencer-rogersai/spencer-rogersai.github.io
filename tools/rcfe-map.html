Map licensed California RCFEs from the CDSS residential elder care file, by county, city and bed count, with citation history.

Load CDSS file

Upload the CDSS residential elder care export (CSV). Closed and on-probation facilities are left out; licensed and pending facilities are mapped as soon as the file loads.

Exact street addresses (optional)

Facilities are placed at their ZIP code center by default, which is accurate enough at county and city zoom. To place them at their actual street address, run the file through the U.S. Census Bureau's free batch geocoder. It takes about ten seconds and matches roughly 95% of the list. Results are remembered in this browser, so this is a one-time step per CDSS file.

  1. Export the address list below.
  2. Upload it at the Census batch address geocoder, leaving the benchmark on its default, and download the result.
  3. Bring that result file back here.

Reference location

Distances are straight-line miles from this point to each facility’s ZIP code center. A California city or 5-digit ZIP resolves instantly; a street address needs an internet lookup.
