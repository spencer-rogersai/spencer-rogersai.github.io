Before you open one

Each tool is an empty map until you give it data. Download the current file from the source below, then load it with the button inside the tool. The file stays on your computer; the tools have no server and send nothing anywhere.

  • Community Care Licensing Facilities California Department of Social Services. Home Care Organization and Residential Care Facilities for the Elderly resources feed the first two tools.
  • Healthcare Facility Locations California Department of Public Health. Refreshed monthly; check the DATA_DATE column to confirm you have the newest extract.

Status

This is a staging index, not a release. Versions here may move without notice and the tools have not been through outside review. Figures on this page were measured against the September 2026 extracts and will drift as the source files are refreshed.
